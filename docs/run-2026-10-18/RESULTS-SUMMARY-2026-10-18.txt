7. SCOPE AND CAVEATS
--------------------------------------------------------------------------
  - The run measures gemini-3.5-flash-lite. The study design was written
    against gemini-3.8-flash, which the free tier caps at 20 requests/day on
    this project (~10 days for the grid); the Flash-Lite tier allows 500/day.
    These figures are NOT comparable to a 3.8-Flash run, and Sections 2 and
    13 of the paper still describe the earlier model.
  - With zero fabrications everywhere there is no variance in the dependent
    variable, so the run cannot discriminate between themes, retrieval depths
    or prompt conditions on quotation fidelity. It bounds fabrication rather
    than measuring it.
  - The 31.5% abstention rate is unaudited (see section 3 above).
  - FUZZY_THRESHOLD = 0.80 was chosen on the same controls it is reported on,
    so it is not a validated constant.
  - 3 of 200 generations failed on transient API faults (HTTP 503, connection
    reset, server disconnect) and were retried successfully.

Full method, decisions and limitations: docs/technical-paper.md (Section 6a
for this run). Run order: RUNBOOK.md.
